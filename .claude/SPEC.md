# Project Specification: Voxel Typing Quest (ボクセル・タイピング・クエスト)

## 1. 概要・コンセプト
- **ターゲット**: 小学校低学年（6〜8歳・ブラインドタッチ入門〜ローマ字習得）
- **世界観**: マインクラフト風の3Dボクセル世界。モンスターを倒しながら進み、まれに出現するレア鉱石（金・ダイヤ）を制限時間内に採掘してハイスコアを目指す。
- **コア体験**:
  - **通常フェーズ**: 時間制限なし。手元を見ずに画面内の「3Dボクセルハンド＆キーボード」を見ながら、正確な指でキーを押す基礎練習。
  - **レア鉱石フェーズ（パターンC）**: カウントダウン制限時間つき。「消える前にキーを叩いて掘り切る」スリルと、破壊時の大量ボクセル飛散による爽快感。
- **技術スタック**: TypeScript, Three.js, Vite, Web Audio API (外部3Dモデル・外部音声ファイル無しで初期動作し、後からアセット差し替え可能な設計)

## 2. 難易度・ステージ設計（マルチレベル対応）
タイトル画面またはステージ選択画面で、子供の習熟度に合わせて以下の難易度コースを選択可能にする。各コース内で「通常モンスター」「金鉱石」「ダイヤ鉱石」の出題内容が動的に変化する。

| 難易度ID | コース名 | 対象・目的 | 通常モンスターの出題 | 金鉱石（制限時間: 8秒） | ダイヤ鉱石（制限時間: 10秒） |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Lv.1** | **はじまりの森**<br>(ホームポジション) | 指を置く位置を覚える | `F`, `J` の単一キー（1打で撃破） | `D`, `K`, `F`, `J` からランダム2連続 | ホームポジション列（`A,S,D,F,J,K,L`）から3連続 |
| **Lv.2** | **あいうえおの草原**<br>(母音マスター) | 母音5つの指を覚える | `A(あ)`, `I(い)`, `U(う)`, `E(え)`, `O(お)`（1打） | 母音からランダム3連続（例: `A`→`I`→`U`） | 母音からランダム5連続（5回ツルハシを当てて破壊） |
| **Lv.3** | **ローマ字の洞窟**<br>(子音＋母音) | 2打で1文字を作る練習 | か行・さ行・た行等の1文字（例: `KA(か)` の2打） | 2文字の短い言葉（例: `NEKO(ねこ)` 等 4打） | 3文字の言葉（例: `SAKURA(さくら)` 等 6打） |
| **Lv.4** | **たつじんの火山**<br>(スピード＆単語) | 実践的なブラインドタッチ | 2〜3文字の単語（例: `INU`, `SORA`） | 3〜4文字の単語（制限時間6秒に短縮） | 4〜5文字の単語（例: `DAIYAMONDO` 等） |

※データ構造上、JSON/設定ファイルにコースを追加するだけで新しい難易度（例：「濁音コース」「拗音コース」など）を後から無限に増やせる設計とすること。

## 3. ゲーム進行とメカニクス詳細
### 3.1 通常モンスター（基礎練習フェーズ）
- **挙動**: 画面奥からボクセルモンスター（スライム、ゾンビ、スケルトン風など）が歩いてきて、プレイヤーの目の前で待機する。時間制限によるゲームオーバーやダメージは一切なし。
- **正解時**: 剣の斬撃エフェクト＋ヒット音が鳴り、モンスターが数十個の小ボクセルに砕け散って地面で跳ね、スコアとしてプレイヤーに吸い込まれる。
- **ミスタイプ時**: ペナルティ（減点）なし。「カン！」と盾で弾かれる軽い演出とともに、画面下の3Dキーボード上で**「今押してしまったキー（赤く揺れる）」**と**「本来押すべき正解キー（緑に強く光る）」**を同時表示し、「隣のキーだったね！」と視覚的に位置関係をフィードバックする。

### 3.2 レア鉱石：金・ダイヤ（タイムアタック採掘フェーズ）
- **出現条件**: 通常モンスターを3〜4体倒すごとに、「チャリーン！レア鉱石が出現！」という演出とともに金鉱石またはダイヤ鉱石が降ってくる。
- **カウントダウン仕様（パターンC）**:
  - 鉱石の上部に分かりやすい**3DまたはUIのカウントダウンゲージ（残り秒数バー）**を表示。残り時間が少なくなると鉱石が点滅してドキドキ感を演出。
  - 指定された複数のキー（例：3打〜6打）を1つ正しく打つごとに、ツルハシが当たって鉱石にヒビが入り、小粒の宝石パーティクルが飛び散る。
  - **採掘成功（時間内に全キー入力完了）**: 特大の爆発エフェクトとともに金塊・ダイヤブロックが大量に噴き出し、ボーナス高得点を獲得。「すごい！」「大成功！」の大きなひらがなテキスト演出。
  - **時間切れ（失敗時）**: ペナルティや嫌な音は鳴らさず、鉱石が「モコモコ…」と地面に潜って逃げていくコミカルな演出にし、「おしい！つぎはほれるかな？」と優しく表示して通常フェーズへ戻る。

## 4. 3Dボクセル描画＆ブラインドタッチ誘導UI
- **指の色分けシステム (Finger Color Coding)**:
  - 左小指: ピンク / 左薬指: オレンジ / 左中指: きいろ / 左人差し指: みどり
  - 右人差し指: みずいろ / 右中指: あお / 右薬指: むらさき / 右小指: マゼンタ
- **画面上部（70%：3Dバトル＆マイニング空間）**:
  - Three.jsの `BoxGeometry` / `InstancedMesh` を組み合わせたボクセルワールド（草ブロック、木、雲、モンスター、鉱石）。
  - 敵や鉱石の頭上に「ひらがな（大きく）」と「ローマ字（次に打つ文字を指の色で強調）」を表示。
- **画面下部（30%：視線固定用 3Dボクセルキーボード＆ボクセルハンド）**:
  - 画面下部に3Dの立体キーボードと、ブロックで作られた可愛い両手（ボクセルハンド）を常時表示。
  - 次に打つべきキーと、それに対応する指が同じ色で光り、上下にバウンスして「この指でここを押すよ」とナビゲートする（子供が手元の実物キーボードを見なくても済む仕組み）。

## 5. サウンドシステム（Hybrid Audio Manager）
- **フォールバック合成音（初期状態）**: Web Audio APIのオシレーターとノイズ生成を用い、外部ファイル無しでマイクラ風の「ポコッ（通常ヒット）」「ガキン！（ツルハシ採掘）」「カン！（ミス）」「キラキラ〜！（ダイヤ撃破ファンファーレ）」をプログラム生成して鳴らす。
- **外部音源ローダー**: `public/audio/` に `bgm.mp3`, `hit.wav` 等が配置された場合、または設定ファイルでパスが指定された場合は、自動的に外部音声ファイルの再生を優先する。
