# 0003 開始前のカウントダウン
- 日付: 2026-10-26
- 状態: 確定
- 関係する SPEC: 3.3 ゲームの終了条件とスコア（タイムアタック）

## 背景
ユーザーより「ゲームの開始が唐突のため、カウントダウンを追加してください」。0002 で全体の制限時間を入れたため、コースを選んだ瞬間に時間が減り始めていた。

## 決定
- 「タイトル画面でレベルを選択後、３・２・１・スタート！の後に開始する」（ユーザー指示）。結果画面の「もういちど」からの再スタートも同じ流れにする。
- カウントダウン中は全体の時間を進めず、キー入力も受け付けない（Esc でコース選択に戻ることだけはできる）。
- 「スタート！」が表示された瞬間にモンスターが現れ、時間が進み始める。
- 1つぶんの長さ（0.8秒）と数（3から）は Claude が仮に決めた値。`src/data/gameRules.ts` の `countdownStep` / `countdownFrom` で調整する。
- 数字ごとに「select」音、「スタート！」で「success」音を鳴らす（既存の効果音を流用）。
